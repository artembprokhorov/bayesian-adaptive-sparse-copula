# Bayesian Adaptive Sparse Copula

Quarto Reveal.js presentation on the Bayesian adaptive sparse copula paper.

## View the slides

Open the published presentation: [Bayesian Adaptive Sparse Copula](bayesian-adaptive-sparse-copula.html).

## Render locally

Install [Quarto](https://quarto.org), then run:

```bash
quarto render bayesian-adaptive-sparse-copula.qmd
```

Open `bayesian-adaptive-sparse-copula.html` in a browser. The rendered HTML uses files in `bayesian-adaptive-sparse-copula_files/`; keep that folder alongside the HTML when publishing or moving the deck.

The paper figures used in the presentation are included under `figures/`.
